— Tentang aplikasi

Catur.ID

Aplikasi kalender turnamen catur Indonesia yang fokus pada wilayah Jabodetabek (Jakarta, Bogor, Depok, Tangerang, Bekasi) dan Bandung — dengan tetap menampilkan event nasional di luar wilayah tersebut.

Data di-aggregate secara otomatis dari beberapa sumber resmi:

  • • chess-results.com — official FIDE Swiss-Manager results server
  • • PB PERCASI — federasi catur Indonesia
  • • ChessPrime — kalender internasional
  • • Festival Catur ID — event kalender Indonesia
Refresh data: Jalankan python scrape_tournaments.py untuk update tournaments.json dari sumber chess-results.com. Auto-filter hanya menampilkan turnamen ≥ hari ini sampai 1 tahun ke depan.
